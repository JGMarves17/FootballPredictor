## 📋 Antes de cada jornada
1. Abrir `QuinielaRunnerV2.java`
2. Actualizar `jornada = N` y `matchday` con los partidos del día
3. Correr `QuinielaRunnerV2` (Ctrl+Shift+F10)
4. Copiar predicciones óptimas al WhatsApp
5. ENVIAR antes del primer partido

## 📝 Después de cada jornada
1. Agregar resultados a `wcHistory` en `QuinielaRunnerV2.java`
2. Si hay xG, agregar a `data/xg_wc2026.json`
3. Actualizar tabla de clasificación (mapa `standings`)
4. Commit → `git add . && git commit -m "jornada N resultados"`
